사용자 관리 필터 상태 유지

승인된 사용자 탭의 필터·정렬·페이지 상태가 다른 사용자 관리 탭을 다녀와도 유지된다.

변경검증위험과 롤백

변경 맵

파일영역이유 / 흐름
app/admin/users/appearance/page.tsx탭 콘텐츠탭 0의 필터 패널과 테이블을 조건부 언마운트하지 않고 hidden으로 감춘다. 탭 0 → 다른 탭 → 탭 0에서 동일한 React 인스턴스가 유지된다.

Diff

117- {activeTab === 0 && (<Box>...</Box>)}
117+ <Box hidden={activeTab !== 0}>...</Box>

필터 적용 함수·API 요청·필터 필드 구조는 변경하지 않았다. 기존 useState 상태를 그대로 보존한다.

검증

  • git diff --check 통과
  • rg -n "hidden={activeTab !== 0}|activeTab === 0" app/admin/users/appearance/page.tsx로 탭 0이 숨김 처리되고 이전 언마운트 조건이 제거된 것 확인
  • 로컬 node_modules가 없어 Jest/Next build는 실행하지 못했다. 프로덕션 런타임 확인도 아직 배포 전이라 미실행이다.

위험과 롤백

탭 0의 테이블은 숨겨진 동안에도 메모리에 남는다. 목록 데이터를 이미 보유하므로 추가 API 호출은 발생하지 않는다. 페이지를 새로 열면 상태는 기존과 같이 초기화된다.

롤백은 app/admin/users/appearance/page.tsx의 hidden 컨테이너를 이전 activeTab === 0 조건부 렌더링으로 되돌리면 된다.

세션 범위: 이 파일의 한 hunk만 포함. 작업 시작 전 기존 변경은 없었다.
